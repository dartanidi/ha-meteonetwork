## Meteonetwork Integration for Home Assistant

Integrates your Meteonetwork weather station data directly into Home Assistant.

### Features

- Real-time weather data from your personal station
- 12 different sensors (temperature, humidity, wind, rain, etc.)
- Configurable update intervals
- Easy setup through Home Assistant UI

### Requirements

- Active Meteonetwork account
- API token from Meteonetwork
- Your station code

### Quick Setup

1. Install via HACS or manually
2. Go to Configuration → Integrations
3. Add "Meteonetwork" integration
4. Enter your station code and API token
5. Choose polling interval (1-60 minutes)
